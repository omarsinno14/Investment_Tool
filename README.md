# Investment Tool

A modern static site for **Invest Scout**, showcasing an investment research and planning experience with a sleek UI and interactive growth calculator.

## Preview
Open `invest-scout/index.html` in your browser or serve the directory locally:

```bash
cd invest-scout
python -m http.server 8000
```

## Features
- Responsive landing page with sticky navigation and CTA flows
- Interactive projection sandbox that updates totals as you type
- Risk presets for conservative, balanced, or aggressive strategies
- Toast feedback on access requests and animated allocation highlights
- Accessible semantics with labeled controls and live regions
